# Figures

All figures, organised by pipeline stage. Data arrays live under `data/` (kept separate from figures).
Folders are numbered in pipeline order so the story reads top to bottom.

| Folder | What it shows | Generated by |
|---|---|---|
| `1_lc2_pose_registration/` | Per-scan probe-pose fan: initial vs LC2-refined (15 scans) | LC2 refinement plotting |
| `2_cbct_us_reslice_check/` | Per-scan CBCT reslice vs real US sanity grids (15 scans) | `plot_script/plots_reslice/compare.py` |
| `3_trajectory_coverage/` | Where the real rosbag scans went (belly-up overview + per-sequence grid) | `plot_script/plots_reslice/trajectories.py` |
| `4_novel_trajectory_tilt/` | **Paper figure** — novel trajectories by probe tilt: same in-volume spot, tilted beam → new anatomy | `plot_script/plots_reslice/tilt_novelty.py` |
| `5_renderer_training/` | CUT renderer training (ep300, b2). See sub-folders below | `plot_script/plots_renderer/compare_cut.py` |
| `6_renderer_eval_paired_vs_unpaired/` | Quantitative eval: paired vs unpaired on LC2-paired frames (SSIM/PSNR/L1 + realism + speckle) — **paired wins 6/0** | `renderer_training/renderer_eval.py` |
| `7_rendered_us_from_novel_tilt/` | End-to-end: novel tilt poses → CBCT slice → paired-CUT → pseudo-US. `preview_generated_us` (8-frame sample), `all_generated_us` (contact sheet of **all 243**), `cbct_to_us_per_sweep` (one CBCT→US pair per sweep) | `renderer_training/render_us_from_poses.py` (render) + `plot_script/plots_renderer/rendered_us_gallery.py` (gallery) |
| `8_novel_render_quality/` | **GT-free quality** of the novel pseudo-US: (A) realism vs real US, (B) input in-distribution, (D) artifact prevalence | `renderer_training/novel_render_eval.py` (metrics JSON → `data/novel_render_eval/`) |

### `5_renderer_training/` sub-folders
| Sub-folder | Content |
|---|---|
| `loss/` | Paired vs unpaired training-loss curves |
| `paired_vs_real/` | Per-scan: CBCT \| paired-generated US \| real US |
| `unpaired_vs_real/` | Per-scan: CBCT \| unpaired-generated US \| real US |
| `cbct_us_pairs/` | Per-scan CBCT↔real-US pair sanity (training data) |
| `lc2_pair_sanity/` | Per-scan LC2-refined CBCT vs real US pair check |
| `cut_training_summary.txt` | Loss summary numbers |

Most figures are saved as both `.png` (300 dpi) and `.pdf` (vector, for LaTeX).
